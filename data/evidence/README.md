# Sample evidence documents

Fictional contractor evidence for the Evidence page, generated by
`backend/scripts/make_evidence_samples.py` (run from `backend/` with
`poetry run python -m scripts.make_evidence_samples`). Every page carries a
"SAMPLE DATA" footer.

| File | Stadium | Type | Stated values | Expected result |
|---|---|---|---|---|
| `samples/ksis-media-areas-drawing-rev-B.pdf` | King Salman International | Drawing | STA-0040 180 m², STA-0042 230 m², STA-0066 6 positions | STA-0040 fails |
| `samples/ksis-dressing-rooms-calculation-rev-A.pdf` | King Salman International | Calculation | STA-0034 86, STA-0035 22, STA-0028 110, STA-0038 52, STA-0039 34 m² | STA-0035 and STA-0039 fail |
| `samples/ars-backup-power-test-record.pdf` | Aramco | Test record | STA-0087 3.5 h, STA-0093 0.52 STI | STA-0093 fails |
| `samples/kfsc-seating-certificate.pdf` | King Fahad Sports City | Certificate | STA-0004 58,400 seats, STA-0007 0.8 % | STA-0004 fails (below 60,000) |

`readings.json` holds the text of each page, bundled with the frontend so the
browser can read these PDFs. Text and Markdown files are read directly; any
other file is identified from its name only and needs its type chosen.
